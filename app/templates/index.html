Documentation

  • WhatsApp upload accepts one or more `.txt` files using the same `file` field.
  • Folder upload works in browsers that support directory selection.
  • Manual entry sends `name`, `phone`, `requirement`, `location`, `budget`, `notes`, and `source`.
  • Data management reads directly from the database structured dataset.
support

Support

  • If uploads fail, check that the file extension is `.txt`.
  • If writes fail, inspect the Last Response panel for the database error.
  • If data view is empty, process or sync a dataset first.
  • Use the Last Response panel below to inspect API status and error details.
